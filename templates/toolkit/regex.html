Regular Operations

Type an expression. See the strings it produces, one path and one iteration at a time.

Iterations4
*
Kleene star: repeat the previous part zero or more times (iteration j repeats it j-1 times)
+
Kleene plus: repeat the previous part one or more times (iteration j repeats it j times)
|
Alternation (union): either the left or the right; each choice becomes its own path
( )
Group parts so an operator applies to all of them
AB
Concatenation: one part followed by the next
